계산 기준

S1은 각 직원이 한 PCB의 서로 다른 작업을 순서대로 담당합니다. S1 Cycle은 직원별 시간의 최댓값입니다. 인원을 추가해도 작업시간이 자동으로 감소하지 않습니다. 균등 배분은 기존 작업시간 합계를 인원수로 나누는 비교안입니다.

S2는 공정별 동일한 병렬 작업대와 공정 전용 인원 풀을 가정합니다. 출력 간격 = max(처리시간 ÷ 병렬 수, 수작업시간 ÷ 인원). 수작업은 처리 시작 부분에 이루어지고 나머지 시간에는 자동 동작한다고 가정합니다. 작업자 한 명이 여러 설비를 맡을 때 이동·간섭 시간은 따로 포함하세요. 공정 간 인원 공유는 계산하지 않습니다.

Line CAPA = 3600 ÷ 최대 출력 간격. LOB = 총 수작업시간 ÷ (총 인원 × Line Cycle). 기존 Excel CAPA는 참고용이며 목표·계산값으로 자동 사용하지 않습니다. S2 CAPA를 수정하면 기존 수작업 비율을 유지하며 처리시간을 역산합니다.

Simulation은 빈 라인에서 시작하며 FIFO, 공정 사이 무제한 대기 공간, 이동시간 0, 불량·돌발정지 없음 조건으로 계산합니다. Run 결과는 초기 통과시간을 반영하므로 정상상태 CAPA × 시간과 다를 수 있습니다. 최대 100,000개까지 계산합니다. 배치는 비율 도식이며 실제 설비 치수가 아닙니다.
