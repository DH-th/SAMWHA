계산 기준

S1: 한 PCB의 작업을 직원별로 순차 분담. S2: 동일 공정이 입력한 개수만큼 병렬 작업. 공정 CAPA = 개수 × PCB Array × 3600 ÷ 시간. 예: 1개 · 30초 · Array 4 → 480/H.

라인 CAPA는 가장 느린 공정 기준입니다. LOB = 공정별 시간 ÷ Array의 합계 ÷ (S1 인원 + S2 개수) ÷ 라인 Cycle × 100. 실제 인원 가동률이 아닌 작업 위치의 이론 밸런스입니다.

모델은 같은 Plant 안에서 숫자 코드 끝의 알파벳 1글자를 제외해 통합합니다. 기존 Excel CAPA는 참고용이며 값이 다르면 범위로 표시합니다. Excel 원본은 수정하지 않습니다.

Simulation: 빈 라인 시작, FIFO, 이동·정지·불량 없음, 공정별 Array 수량이 모이면 작업 시작, 최대 100,000개. S1 입력 시간은 PCB 1개 기준입니다. 입력 시간은 휴식을 제외한 순가동 시간입니다.
